# 一、系统启动过程

```
sync //将数据由内存同步到硬盘中
shutdown //关机命令
shutdown -h now //立刻关机
shutdown -h 20:25 //今晚20：25关机
shutdown -h +10 //十分钟后关机

shutdown -r now  //立刻重启
shutdown -r +10  //十分钟后重启

ctrl+d // 等于输入 exit，结束键盘输入
shift + PgUp //往前翻页
shift + PgDn //往后翻页

```

reboot 重启，等于 shutdown -r now
halt 关闭系统,等于shutdown -h now 和poweroff

## `-p` 参数作用

1. **普通 `mkdir`**：如果目录**已经存在**，直接报错：`mkdir: cannot create directory ‘test’: File exists`
2. **`mkdir -p`**：

  - 目录不存在 → 创建目录
  - **目录已经存在 → 不报错，静默跳过**（图里就是这个效果，命令执行完没有任何输出）
  - 还可以一次性创建多级目录，例如 `mkdir -p a/b/c`，父目录不存在也能一并创建

## 结论

**会影响**：

- 不加 `-p`：重复创建同名目录会报错
- 加 `-p`：重复创建已存在目录不会报错；同时支持创建嵌套多级目录

| -i               | 如果目标目录或文件存在，提示是否覆盖已有文件                                                                                    |
| -R               | 递归复制目录，即包含目录下各级子目录                                                                                        |
| -r               | 加上可以复制目录，但文件与目录的权限可能会被改变                                                                                  |
| -u               | 目标文件与来源文件一差异时，常用于**备份**                                                                                   |
|                  |                                                                                                           |
### (1)为什么复制目录**必须加 `-r / -R`**

`cp` 默认**只能复制文件**。

> 如果你直接 `cp 目录A /tmp`，不加 `-r/-R`，会直接报错，**不会复制目录里面任何内容**。

- `-r`：递归复制目录，会把目录里面所有子目录、文件一起拷贝；缺点：**权限、时间等属性不会完整保留**
- `-R`：同样递归复制目录；相比 `-r`，对特殊文件（符号链接、设备文件）处理更规范
- `-a` = `-R + 保留所有属性`，**做目录备份首选**，相当于归档复制

> 一句话：**cp 默认只能拷贝单个文件；拷贝文件夹，必须开启递归，才能把里面一层一层内容全部拿出来**。

### 区分两种场景

1. **复制文件**（不用任何参数）

```
cp /var/log/wtmp .

```

1. **复制目录**（必须 `-r` / `-R` / `-a`）

```
cp -r /var/log /tmp

```

### (2)`-u` 参数是什么？什么时候用？

`-u` = update，**增量复制，只在下面两种情况才复制**：

1. 目标文件**不存在** → 复制
2. 目标文件**存在，但源文件更新（修改时间比目标新）** → 覆盖旧的目标文件

> 如果目标文件已经存在，而且**比源文件新**，就**跳过，不复制**。

### 适用场景：备份！

比如你定期备份日志目录：

```
cp -ru /var/log /tmp/backup

```

每次执行，**只拷贝新增 / 修改过的文件，不变的旧文件不重复覆盖**，节省时间。

对比：

- 不带 `-u`：每次全部覆盖，不管文件有没有改动
- 带 `-u`：**有差异才复制**，适合增量备份

### (3)理清：源、目标的两种模式（非常容易混淆）

`cp` 有两种工作逻辑：

### 模式 A：目标是**不存在的文件名** → 复制并重命名

```
cp ~/.bashrc /tmp/mybash

```

源：`~/.bashrc`（文件）
目标：`/tmp/mybash`（新文件名）
👉 把源文件复制一份，命名成 mybash 放到 /tmp

### 模式 B：目标是**已经存在的目录** → 把源丢进这个目录里面（文件名不变）

```
cp ~/.bashrc /tmp

```

`/tmp` 本身就是已存在目录，所以：把 `.bashrc` 复制到 `/tmp` 目录内，文件名保持 `.bashrc`

> ✅ 记住：
>
>
>
> - 目标是**目录**：文件放进目录，原名不变
> - 目标是**文件名**：复制并改名

### （1）mv 移动目录的时候，可以顺便改名；分两种情况

#### 情况 1：目标**不存在** → 移动 + 改名（最常用）

```
# 把 /root/dir1 移动到 /tmp，并且改名叫 newdir
mv /root/dir1 /tmp/newdir

```

- `/tmp/newdir` 这个名字**原本不存在**
- 效果：把整个 dir1 目录剪切过去，名字变成 newdir

#### 情况 2：目标**是已经存在的目录** → 只移动进去，**不会改名**

```
# /tmp 目录本身就已经存在
mv /root/dir1 /tmp

```

效果：把 dir1 整个文件夹**放进 /tmp 里面**，目录名字**仍然叫 dir1**，不会改名。

---

### 📌 对比记忆（文件 / 目录通用，mv 对文件和目录规则一样）

1. **目标不存在**：移动 + 重命名
2. **目标是已存在目录**：把源丢进目标目录内部，原名保留

> ⚠️ 重点区别于 cp：
>
>
>
> - `cp`复制目录必须加 `-r/-R`
> - **mv 移动目录，不需要任何参数！直接 mv 即可**（mv 是剪切，不需要递归参数）

#### 实操小例

```
# 创建测试目录
mkdir olddir

# ① 移动并重命名：/tmp里没有newname目录
mv olddir /tmp/newname

# ② 再把newname移回/root，不改名（目标/root已存在）
mv /tmp/newname ~

```

#### 补充：mv 能不能只改名，不移动位置？

可以！源和目标在同一个目录下，就是单纯改名：

```
mv oldname newname

```

不管是文件还是目录，直接改名。

## 巩固

如果 `/tmp` 目录已经存在，执行：
`mv testdir /tmp/test2`

- 若 `/tmp/test2` **不存在**：移动 testdir 到 /tmp，改名 test2
- 若 `/tmp/test2` **已经是一个目录**：把 testdir 放到 /tmp/test2/ 里面，名字不变

# nano 编辑器操作说明

> `Ctrl+O` = WriteOut（保存）；`Ctrl+X` = Exit（退出）

## ✅正确顺序

1. 修改完文件内容
2. 按下 **`Ctrl + O`** （字母 O，不是数字 0！！很多人按错成 0，就没反应）
3. 底部会出现提示：`File Name to Write: xxx`
4. **直接按回车 Enter**，确认写入当前文件
5. 再按 **`Ctrl + X`** 退出编辑器
